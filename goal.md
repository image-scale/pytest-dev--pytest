# Goal

## Project
pytest — a python project.

## Description
A Python testing framework that makes it easy to write small, readable tests while scaling to support complex functional testing. Core capabilities include automatic test discovery, rich assertion introspection, a powerful fixture system for dependency injection, test parametrization, markers for controlling test execution (skip, xfail), exception and warning testing utilities, monkeypatching, output capture, and temporary directory management.

## Scope
- ~15 production source files to implement
- ~11 test files to write
- Reproduce all core source code, tests, and configuration
